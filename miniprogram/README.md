# 去水印微信小程序（原生框架）

原生微信小程序源码（WXML / WXSS / JS），对接外部解析后端实现短视频去水印：粘贴分享链接 → 解析无水印直链 → 在线预览 / 保存到相册。

## 目录结构

```
miniprogram/
├── app.js                  # 全局：baseUrl 管理、request 封装、toast 工具
├── app.json                # 页面路由 + tabBar（首页/历史/设置）
├── app.wxss                # 全局样式
├── sitemap.json            # 默认不被微信搜索收录
├── project.config.json     # 工程配置（appid 为占位符，见下）
├── images/                 # tabBar 图标（灰/蓝两套）
├── pages/
│   ├── index/              # 首页：粘贴链接 → 解析 → 预览 → 保存/复制
│   ├── history/            # 历史：本地最近 20 条记录，可回看、可清空
│   └── settings/           # 设置：接口地址、支持平台、使用说明、免责声明
└── README.md               # 本文件
```

## 1. 导入到微信开发者工具

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 打开工具 → 「导入项目」→ 项目目录选择本仓库的 `miniprogram/` 文件夹。
3. 「AppID」填你自己的小程序 AppID（没有就先去注册，见第 2 节），项目名称随意，后端服务可先选「不使用云服务」。
4. 导入后点「编译」即可在模拟器预览。

## 2. 替换 AppID（必须）

`project.config.json` 中的 `"appid": "wx0000000000000000"` 是**占位符**，共两处提醒：

- `project.config.json` → `appid` 字段（以及同文件 `description` 字段里有中文提醒）
- `app.js` 顶部注释

替换方式（二选一）：

- 在开发者工具顶部菜单把测试号 AppID 切换为你自己的 AppID 后重新「导入项目」；
- 或直接用编辑器打开 `project.config.json`，把 `appid` 的值改成你的真实 AppID。

> 注：JSON 规范不支持注释，所以提醒文字放在了 `description` 字段和 `app.js` 头部注释里，而不是写在 `appid` 行内。

获取 AppID：前往 [微信公众平台](https://mp.weixin.qq.com) → 注册「小程序」账号（需实名）→ 「开发」→「开发管理」→「开发设置」中查看。

## 3. 配置 request 合法域名（必须，否则真机请求失败）

小程序向后端发请求（`wx.request`）和下载视频（`wx.downloadFile`）都必须把域名加入白名单，否则在真机上会被微信直接拦截（开发工具里勾选「不校验合法域名」可临时绕过，仅限调试）。

步骤：

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 「开发」→「开发管理」→「开发设置」→「服务器域名」→ 修改。
2. 在 **request 合法域名** 中添加你的后端域名，例如 `https://api.xxx.com`（注意只填域名，不要带路径；必须是 **https**）。
3. 在 **downloadFile 合法域名** 中添加**视频直链所在的域名**。如果后端返回的 `video_url` 是后端自己代理转发的，填后端域名即可；如果是各平台 CDN 直链（如 `*.douyin.com` 等），需要把用到的 CDN 域名也加进去（建议让后端做一层代理转发，只加后端域名最省事）。
4. uploadFile 用不到，可不填。socket / udp 同理按需。
5. 保存后**约 5–10 分钟生效**，每月可修改 5 次，请谨慎填写。

## 4. 域名备案要求（必须）

- 在国内提供服务、且服务器在境内的域名，必须完成 **ICP 备案**（工信部）后才能用于小程序 request 合法域名；未备案域名微信会校验失败。
- 服务器在境外可免备案，但访问速度和稳定性自行评估；且小程序上架审核时仍需提供可访问的服务。
- 建议：后端部署在腾讯云/阿里云等国内云服务商，随域名一起做备案，一次到位。

## 5. 在小程序里配置后端地址

1. 打开小程序 → 底部「设置」Tab。
2. 在「后端接口地址」输入框填写你的后端地址，如 `https://api.xxx.com`（末尾斜杠可省略）。
3. 点「保存」，地址会用 `wx.setStorageSync` 持久化在本地，重启小程序依然有效。
4. 默认占位地址 `https://api.example.com` 不可用，仅作演示。

## 6. 后端接口契约（给后端同事）

- `POST {baseUrl}/api/parse`，请求体 `{"url": "视频分享链接"}`
  - 成功：`{"ok": true, "platform": "douyin", "platform_name": "抖音", "title": "标题", "author": "作者", "cover": "封面URL", "video_url": "无水印直链", "duration": 12.5}`
  - 失败：`{"ok": false, "code": "unsupported|parse_failed|needs_login|invalid_url", "error": "中文错误信息"}`
- `GET {baseUrl}/api/platforms`，返回平台列表（支持以下任一格式，任选其一即可）：
  - `["douyin", "kuaishou", ...]`，或
  - `[{"id": "douyin", "name": "抖音"}, ...]`，或
  - `{"platforms": [...]}`

## 7. 真机调试常见问题

| 现象 | 原因 / 解法 |
|---|---|
| 真机点解析一直「网络请求失败」 | request 合法域名没配（第 3 节）；或域名未备案 / 非 https |
| 模拟器正常、真机 `downloadFile` 失败 | downloadFile 合法域名没加视频直链域名 |
| 点「保存到相册」没反应 | 未授权相册权限：小程序内会弹窗引导去设置页开启；也可在手机系统设置中检查微信相册权限 |
| 剪贴板自动识别不生效 | 较新版本微信限制非用户手势读取剪贴板，属正常现象，用首页「一键粘贴」按钮即可 |
| 解析返回失败 | 按后端返回的中文 `error` 排查；也可能是该平台反爬升级，需后端跟进修复 |

## 10. 广告变现（流量主）

代码里已集成好两种广告，广告位 ID 留空则不显示、不影响使用。

### 已集成的广告
- **Banner 广告**：首页底部，按展示/点击计费，细水长流
- **激励视频广告**：点"去水印解析"时先看一段视频广告，看完才真正解析——这是去水印工具最标准的变现模式（"看广告免费解析"），单价最高

### 开通步骤
1. 小程序**发布上线**后，登录微信公众平台 → 左侧「流量主」→ 开通（需达到平台要求的用户量门槛，具体以页面显示为准）
2. 流量主后台 → 广告管理 → 新建广告位：
   - 新建一个 **Banner** 广告位，拿到 `adunit-xxx`
   - 新建一个 **激励视频** 广告位，拿到 `adunit-yyy`
3. 把两个 ID 填进 `app.js` 的 `globalData.adConfig`：
   ```js
   adConfig: {
     bannerId: 'adunit-xxxxxxxxxxxxxxxx',
     rewardedVideoId: 'adunit-yyyyyyyyyyyyyyyy',
   },
   ```
4. 在开发者工具里重新「上传」→ 提交审核 → 发布，广告即生效

### 注意事项
- 广告加载失败时代码会自动放行（直接解析），不会把用户挡在门外
- 收益按微信官方分成比例结算到你绑定的结算账户，在流量主后台查看报表
- 不要自己点自己的广告、不要诱导点击，会被判作弊扣钱甚至封号
- 审核时如实描述功能；广告位 ID 不要提交到公开仓库
